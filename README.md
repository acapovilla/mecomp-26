# Mecánica Computacional

Implementación de métodos numéricos y resolución de ejercicios correspondientes a las guías de trabajos prácticos de la materia **Mecánica Computacional** de la carrera de **Ingeniería Informática** de la **Facultad de Ingeniería y Ciencias Hídricas (FICH)** de la **Universidad Nacional del Litoral (UNL)**.

## Entorno de desarrollo

El proyecto utiliza un entorno de desarrollo basado en **Dev Container**, con **Python 3.12**.

Las dependencias de Python se encuentran especificadas en `requirements.txt` y se instalan automáticamente al crear el contenedor.
